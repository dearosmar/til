# TIL — Today I Learned

> 10 minutes a day. Small notes on Swift, app ideas, and English dev logs.
> 하루 10분, 매일 배운 것을 짧게 기록합니다.

## Weekly Routine

| Day | Topic | Folder |
| --- | --- | --- |
| Mon | Swift concept + 5–10 lines of example code | [`swift/`](./swift) |
| Tue | Swift Student Challenge winner analysis (3 lines) | [`ssc-research/`](./ssc-research) |
| Wed | Data model notes for a goods-seller tool | [`goods-tool/`](./goods-tool) |
| Thu | Dev log in English (3–5 sentences) | [`devlog-en/`](./devlog-en) |
| Fri | One easy algorithm problem | [`algorithm/`](./algorithm) |
| Weekend | Rest, or polish one note from the week | — |

## Rules

1. **Commit when the 10-minute timer ends.** Unfinished? Add `WIP` and commit anyway.
2. **One line counts.** On busy days, a single sentence keeps the streak.
3. **Commit message format:** `[topic] one-line summary`
   - e.g. `[swift] actor reentrancy`, `[devlog-en] first week of TIL`

## File Naming

```
swift/2026-11-16-actor-reentrancy.md
ssc-research/2026-11-17-<app-name>.md
goods-tool/2026-11-18-order-model.md
devlog-en/2026-11-19.md
algorithm/2026-11-20-<problem-name>.swift
```

(optional)
